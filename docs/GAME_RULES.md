# Game Rules

## Solo release

- Arena: 24 by 24 cells.
- Start length: 3 cells.
- Input: WASD, arrows or touch.
- A snake cannot reverse directly into itself.
- Yellow food adds one point and one body cell.
- Speed increases every five points.
- Touching a wall or the snake's body ends the round.
- The personal best is stored in the browser.

## Multiplayer target

- Two to four players per private room.
- The host starts the match.
- All players begin at safe, separated spawn positions.
- Head-to-body, wall and self collisions eliminate a snake.
- Simultaneous head-to-head collision eliminates both snakes.
- The last surviving snake wins.
- Eliminated players see a result screen that updates when the winner is known.
